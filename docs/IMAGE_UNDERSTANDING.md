# 图片识别分流与测试

入口为“设置 → 微信与 DSH → 图片解析”，也可从向导模型步骤进入。使用当前 DSH 的模型，不另填一套识图密钥。配置作用于后续图片，不改变原聊天的人格、历史或执行权限。

## 路由规则

当前聊天模型确认支持图片时直接接收原图，不额外调用备用解析器。纯文本模型先由独立识图模型提取客观观察和可辨认文字，再交回原模型回复。关闭分流后，原本支持图片的模型照常看图，纯文本模型不请求备用解析。

目录保留各提供方条目，单个提供方失败不清空其他模型。列表按支持图片、能力待核验、不支持或不适合分组，并支持搜索。名称或能力声明不代替真实调用验证；待核验模型也可手动选择测试。自动选择会核验候选并限制元数据等待，不保证所有账号都有可用备用模型。

## 隔离测试

使用含红色矩形、蓝色圆形与 `WECHATGIRL 42` 的内置图，或上传 PNG/JPEG/WebP。

- “测试分流流程”：检查主模型，能看图则直识，否则走备用解析。
- “只测试备用识图模型”：单独验证所选解析模型。

测试采用页面当前选择，不要求先保存，也不修改正式配置。显示实际模型、路径、耗时和解析文字；取消或离开页面会中止。测试图会交给所选模型服务并使用额度，但不发送微信消息。上传私人图片前确认该服务的数据政策。

## 限制与失败处理

每轮最多 4 张，最多并行解析 2 张，解析文字限制 2400 字符。同账号、聊天、图片与模型结果仅在内存缓存 5 分钟，最多 64 项。取消、账号切换或配置变化阻止过期结果进入对话。

备用解析使用独立超时预算。解析器不读取聊天历史、不调用工具；图片文字按不可信资料处理，不执行指令。低清缩略图明确提示质量限制，失败不编造内容；其他成功图片仍可使用。表情池评选也可在主模型不能看图时选择识图模型。

回归入口：`node --test scripts/test-vision-fallback.mjs`。本机已验证内置图的直识/分流路径；其他账号与模型需实际测试，不将本机模型数量和耗时写成产品保证。
