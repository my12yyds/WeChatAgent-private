# 维护基线与迭代路线图

本文按 0.5.1 功能基线整理；运行包及源码版本字段以实际构建为准。路线图用于维护排序，不构成发布日期或效果承诺。

## 当前已实现

- 首次配置向导、六项基础检查、自动发现可选插件教程及配置返回。
- 聊天/助手模式、按聊天模型与 DSH 能力、真实管理员权限边界。
- 独立发送模式页，前台与 Hook 能力隔离及限制说明。
- API v2 ZIP 插件、九个第一方可导入包、同页按聊天分配。
- 图片直识/备用模型分流、跨提供方目录和隔离测试。
- 音乐登录、站内搜索、音源权限检查、本机成品曲库与复用。
- 本地语音、自定义/随机音色、随机句子语音替换及可选外接 API。
- 人物事实记忆与群内互动记忆、表情诊断、多表情回执关联、首条定向提醒。
- 页面返回、轻量过渡、音乐折叠配置及托盘服务快捷操作。

功能依赖与限制见 [README](../README.md)。实现存在、隔离测试通过、本机真实验收、发行包已上传是不同状态，不能互相代替。

## 0.5.1 发行基线

用户与维护文档、版本字段及隔离发行包已整理；初装、升级保留、归档清单和校验检查已执行，范围见[0.5.1 记录](releases/0.5.1.md)。附件和对应源码以仓库 Release 为准；一台机器的检查不代表所有机器可用。

## 后续候选

| 方向 | 验收重点 |
| --- | --- |
| 干净环境部署 | 将语音所需环境、模型许可与安装检查变为更清楚的逐项清单 |
| 外部服务兼容性 | 为不同 DSH、语音及识别服务保留可复现的版本矩阵和失败分类 |
| 制作与发送性能 | 分开统计加载、推理、编码、队列和回执耗时，依据证据优化 |
| 插件维护 | 改进缺失依赖、配置迁移及撤权后的恢复提示 |
| 界面回归 | 覆盖深色、窄窗口、键盘、减少动态效果及长列表 |
| 发行验证 | 扩大跨 Windows 环境验收，评估签名与自动化构建来源追踪 |

新增候选先写问题、依赖、权限/数据影响、验收和回滚；确认后再标记准备中、进行中或验证中。完成事项进入版本日志，历史路线图不覆盖上游署名和历史记录。
