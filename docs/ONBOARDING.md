# 首次配置与按需功能

首次打开默认进入配置向导，之后仍可从侧栏进入。向导负责显示已保存配置、当前草稿和实际连接状态，不用“已保存”替代“服务就绪”。

## 六项基础配置

| 配置领域 | 完成条件 |
| --- | --- |
| 微信 | 匹配客户端已登录，当前账号和数据库验证通过 |
| DSH | 独立安装、登录并加载本项目插件，连接检查成功 |
| 模型 | 从 DSH 读取目录并选择可用模型 |
| 发送模式 | 看过能力差异并保存前台或 Hook 选择 |
| 服务 | 读取、桥接及所需发送组件就绪 |
| 聊天 | 明确加入允许的好友/群聊，按需要设置人格并自行试聊 |

向导显示顺序以界面为准。设置未完成时先定位失败的一项，不用重复初始化全部数据。DSH 插件导入详见[单独安装 DSH](EXTERNAL_DSH.md)，发送差异见[发送模式](SENDING_MODES.md)。

## 可选功能

“按需开启功能”包括人格、图片分流、管理员权限、表情、联网阅读、压缩、主动聊天及已安装插件。跳转应进入相应配置区域，顶部“返回上一页”回到来源。可选项不阻挡基础聊天，也不默认开启、授权、上传内容或发表朋友圈。

声音、网易云、B 站、人物记忆、朋友圈和语音识别各有教程。插件参数和权限在“能力”维护；聊天分配在“插件与聊天”同页选择，不需要多层菜单。缺少权限先去配置，不通过分配按钮自动补授。

左侧步骤切换仅更新右侧，保持滚动位置；重复点击当前步骤不重绘。状态复用最近检查结果，点击“重新检查”刷新。动画尊重减少动态效果偏好。

## 检查与测试的区别

向导状态检查只读取状态，不发送微信消息、不调用模型、不改权限。**显式点击图片识别、语音合成或识别接口测试，会按按钮提示调用相应服务并可能产生费用。**本机试听与发送到微信的测试按钮分别处理。

## 新功能怎样进入向导

集中入口为 `public/console/feature-setup.mjs`。已安装插件声明 configSchema 或权限后自动进入可选配置清单，只展示字段标题，不显示密钥和值。专门教程在 pluginHelp 登记，宿主功能在 featureSetupItems 登记；同时维护状态条件、步骤、跳转和返回路径。

新增项需区分未检查、已保存、已启用、服务就绪及实际测试结果。不要仅凭启用开关就标记发送验收完成。
