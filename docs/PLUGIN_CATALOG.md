# 插件目录、参数与聊天范围

项目中有两类插件：DSH 插件在 DSH 安装，WeChatGirl API v2 ZIP 插件在“能力 → 能力目录”导入。两者不共用启停、参数或授权状态。

## WeChatGirl 插件

随源码提供九个第一方可导入包，名称、版本和路径由 `packages/plugin-api/bundled.mjs` 统一登记；生成文件见[插件包目录](../optional-extensions/packages/README.md)。示例 chat-notes 单独作为开发示例，不计入九个产品插件。

导入后默认关闭。先配置参数，明确授予权限并选择聊天，再启用。插件更新保留数据并要求重新启用；卸载不等于清除数据。进程隔离和资源限制不构成恶意代码沙箱。

“能力”保留安装、参数、权限和原有聊天范围管理。“插件与聊天”负责同页选群聊/好友并逐项分配，自动保存当前聊天，不静默授予缺少权限。没有模型、API 或运行依赖时，安装成功不代表功能就绪。

## DSH 能力来源

在“聊天 → 设置此聊天 → 能力与权限”按来源查看技能和工具：

| 分类 | 含义 |
| --- | --- |
| 技能 | 当前 DSH 技能目录中的说明 |
| DSH 内置能力 | 预设加载的文件、终端、检索及任务等工具 |
| 插件工具 | 按实际注册来源分组，保留包名、版本和工具 ID |
| 来源未确认 | 无可靠归属，不凭工具名前缀猜测 |
| 已分配但未加载 | 保留旧授权，可取消，恢复连接后再刷新 |
| 无可授权工具的插件 | 仅展示安装信息，界面插件不因此变成工具 |

同名不同包不合并，改名不增加授权。来源由注册上下文读取，不修改 DSH 安装文件。旧 DSH 缺少目录元数据时保留已有权限并提示来源不可用。

dsh-meme 接入在“表情包 → 来源与搜索”配置，不是下载一个同名 ZIP 就会自动接入。详见[DSH 按聊天授权](DSH_CHAT_ACCESS.md)、[dsh-meme](DSH_MEME.md)和[插件开发](PLUGIN_DEVELOPMENT.md)。
