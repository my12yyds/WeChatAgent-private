# 网易云与哔哩哔哩公开内容

在“能力 → 能力目录”导入插件，授予 `web_fetch` 并选择聊天后，可让模型搜索歌曲、视频或读取平台链接。公开资料阅读不要求登录；受限歌曲音源另按[网易云账号](NETEASE_ACCOUNT.md)配置。

| 平台 | 当前支持 | 不应据此推断 |
| --- | --- | --- |
| 网易云 | 站内搜歌、歌曲资料、公开歌单，最多返回 20 条可读取歌曲 | 搜得到就能完整播放，或已经制作翻唱 |
| 哔哩哔哩 | 视频搜索、BV/视频链接/b23 短链、标题、UP 主、简介、时长、分 P、公开字幕 | 已观看画面，或所有视频都有字幕 |

例如：“网易云搜一下晴天 周杰伦”“B站找几个 Minecraft 建筑教程”。无字幕时只返回资料，不把简介伪装成正文。唱歌由声音工作室另行处理。

平台公开接口优先；不可用时可使用公开网页索引，严格筛选对应平台链接并标记“搜索摘要”。都失败时仅给官方搜索入口，不编造结果，不绕过验证、登录或付费限制。

宿主提供 `ctx.media.search({platform,query,limit})` 与 `ctx.media.read({platform,url})`，仅接受 netease / bilibili。请求端点固定，用户链接先提取平台身份再构造请求；短链与字幕域名按规则核验，拒绝内网、任意网址及凭据 URL。单轮总时限 6.5 秒、响应上限 1 MiB。公开查询缓存最多 128 项、5 分钟，不含账号凭据。

本轮禁止联网、撤权、停用或取消后，不继续使用调用结果。安装不自动扩大其他聊天或插件权限。回归：`node --test scripts/test-public-media.mjs`。
