# 新增插件与音乐发送配置说明

先在“能力”安装插件，再到“插件与聊天”选择允许的好友或群。安装不等于启用；关闭和撤权会停止使用，已有本机数据保留。不要只按昵称判断人物身份。

## 音乐发送方式

在音乐页面选择方式，点击“保存为默认方式”。下次普通点歌沿用保存值；只更改下拉框用于本次页面点歌，不会改长期默认。聊天本次要求优先，不会修改默认；已排队任务保持入队时方式。

- 1分钟片段：先裁取最多60秒，再分离、换声和混音，不会先制作整首再截取；不足60秒按实际长度。发送一条原生语音，任务和回执显示片段标识。
- 完整翻唱：处理整首，当前最长10分钟；拆成每段最长55秒，逐段确认送达后继续。取消、撤权或回执不明会停止，避免重复。
- 点歌示例：“播放《晴天》”沿用默认；“只唱《晴天》一分钟”临时选片段；“完整唱一遍《晴天》，分段发送”临时选整首。曲库缓存按模式和音色区分。
- 原生语音发送需要Hook模式、匹配微信、声音插件权限和聊天授权。搜到歌曲不代表账号有完整音源权限；找不到准确音源会明确失败。

## 档案检索助手

从已授权聊天的历史中寻找相关原文，例如把“猫叫什么”和“家里那只毛孩子”关联起来。支持关键词和可选本机语义模型，返回证据而不凭空补写记忆；按微信账号、聊天和真实人物隔离。首次完整检索会后台建立索引，可查看进度。关闭插件保留索引，但停止使用。

| 配置 | 默认值 | 作用与调整建议 |
| --- | --- | --- |
| 使用当前模型重排候选（产生消耗） | false | 仅近期检索模式生效：让当前聊天模型对候选重新排序，可能增加费用和等待；关闭则直接使用关键词排序，模型失败会回退。 |
| 检索近期记录条数 | 100 | 关闭完整档案检索时生效。只读取当前聊天最近这些条消息；调大可覆盖更多近期话题，但不代替完整档案。 |
| 候选条数 | 20 | 仅近期模式的候选数量。模型重排时从这些原文里选证据；越多通常越慢。 |
| 返回证据条数 | 4 | 一次最多交给聊天模型多少条证据。建议先保留4；过多会增加上下文占用。 |
| 实验：启用本机向量混合检索 | false | 默认关闭。开启后调用本机嵌入服务理解近义表达，需要额外模型环境和model_embed权限；不可用时回退关键词，不自动上传到云端。 |
| 本机嵌入服务地址 | "http://127.0.0.1:19884/v1/embeddings" | 本机兼容/v1/embeddings的HTTP地址，只允许127.0.0.1。内置服务默认19884端口；地址改变会使用独立索引，首次需重新建立。 |
| 嵌入模型 ID | "multilingual-minilm-l12-v2-q8" | 内置模型填multilingual-minilm-l12-v2-q8。外接本机服务填实际模型ID；只修改名字不会下载模型。切换模型会建立独立向量索引。 |
| 语义分数权重 | 0.65 | 范围0–1，默认0.65。越高越重视语义接近，越低越重视原文关键词；仅向量服务正常时生效，时间新近度另作少量排序参考。 |
| 检索完整聊天档案（后台索引） | true | 开启则在后台按批索引完整聊天档案，不限近期100条；首次可能暂时没有结果，稍后重试或用索引工具看进度。关闭后使用近期检索。 |
| 每个聊天索引分片上限 | 50000 | 默认50000个文本分块，每块约500字符。一条长消息可能拆多块；达到上限会标明受限。不是模型上下文长度，也不会删除原始聊天。 |
| 语义召回最低相似度 | 0.25 | 0–1，默认0.25；没有关键词命中时，语义相似度至少达到此值才返回。过高容易漏记，过低可能混入无关资料。 |

## 事件与约定

把本人明确说出的计划与约定记成独立事件，保存参与人、时间、计划中/已完成/已取消状态。参与人使用真实身份核验，同名不合并；未知日期不猜测，完成与取消也需要本人明确说明。仅当前授权人物和聊天可查，不会自动发提醒。

| 配置 | 默认值 | 作用与调整建议 |
| --- | --- | --- |
| 同时记录本人明确事实（默认关闭） | false | 默认关闭。开启后额外把本人明确事实交给人物记忆服务记录，需要人物记忆权限；事件记录工具本身不依赖此开关。不会把转述或引用当成本人事实。 |
| 每位人物在当前聊天的事件容量 | 64 | 每位人物在当前聊天最多保存的事件数。达到容量时会拒绝新增，不自动覆盖未完成约定；可先完成、取消或调整容量。 |
| 计划中事件保留天数（新记录） | 30 | 新建计划从记录时间开始的保留天数，默认30天。到期后列表不再显示；修改不批量改写旧记录，也不是自动提醒时间。 |
| 完成或取消后保留天数 | 7 | 明确完成或取消后重新计算保留天数，默认7天。用于保留近期结果，和计划中的保留期限分开。 |

## 自然群聊节奏

把“现在要不要接话”和“怎么说”分开控制，减少群里抢话、重复套话与无意义追问。只作用于已授权群聊的社交模式；直接点名或唤醒的请求不受闲聊概率和冷却抑制。可先运行虚构场景回放，不调用模型，也不发送微信。

| 配置 | 默认值 | 作用与调整建议 |
| --- | --- | --- |
| 非直接点名的接话冷却（秒） | 30 | 上一次实际回复后，普通环境闲聊至少等待多少秒再考虑接话。默认30秒，0关闭冷却；直接点名不受此限制，私聊和任务模式不受影响。 |
| 非直接点名的接话概率（%） | 35 | 通过冷却检查的普通群聊发言，按此百分比决定是否接话。35表示约35%，不保证每三条回一条；0不主动接环境闲聊，100每次都考虑接话，点名始终放行。 |
| 抑制重复表达 | true | 开启后抑制近期完全相同的环境闲聊回复，避免反复说同一句；保留最近5条进行对比。直接点名追问不因此丢失回复，重启后本轮缓存清空。 |
| 表达提示：最多自然追问数 | 1 | 给模型的表达提示：每条回复最多自然追问几次，默认1，0提示不主动追问。它是表达约束，不保证模型百分之百遵守，也不禁止回答用户的问题。 |

## 原生肥鱼 CosyVoice3

提供专用肥鱼CosyVoice3本机常驻合成，与Breeze参考克隆分开选择。需独立准备模型与环境；插件ZIP不含权重。首次加载较慢，驻留后可复用。它只选择设备引擎，微信发送仍受声音插件权限和聊天范围控制；外接API、自定义参考与自然A保持各自路径。

| 配置 | 默认值 | 作用与调整建议 |
| --- | --- | --- |
| 内置肥鱼语音引擎 | "breeze" | Breeze沿用现有语音；CosyVoice3让内置明亮可爱B/温柔使用专用肥鱼权重直接生成，不再经过RVC。自然A和自定义参考仍走Breeze，外接API优先。保存后重启语音服务，新任务使用新选择。 |
| 专用本机服务端口 | 19886 | 专用本机服务端口，默认19886；不需要公网地址。更改后重启语音服务，注意不要与Breeze、唱歌或其他程序端口重复。 |
| 允许本机同文本对比试听 | true | 开启后可在语音音色页用同一句文字分别生成Breeze和CosyVoice3试听，仅在本机播放，不发微信。即使当前选择Breeze，也会准备Cosy服务并占用部分内存/显存；关闭则禁止对比。 |

## 虚构长对话评测

用固定虚构人物和100/500条消息检测旧事召回、昵称纠正、同名分离、跨群隐私与拒绝共享。分别评估资料召回和模型回答，不读真实聊天，不发微信；会调用当前选择的模型并消耗额度。测试通过只代表这些固定案例，不保证所有聊天永远记得。

| 配置 | 默认值 | 作用与调整建议 |
| --- | --- | --- |
| 允许模型评测（产生模型额度消耗） | false | 默认关闭。开启只是允许运行固定虚构评测，不会自动开始；执行时仍需明确确认。评测会使用所选聊天模型的额度，结果不写入真实人物记忆。 |

## 人物记忆的保留期限

人物记忆插件分别配置昵称730天、长期事实180天和临时计划7天；事件插件的计划/关闭事件期限单独设置。更改期限只影响之后新记录，不批量重写已有记忆。跨聊天召回仍要求真实身份一致、来源聊天已授权以及本人允许共享。详细配置见 [人物记忆](../optional-extensions/people-memory/README.md)。

## 阅读字号与插件分类

右上角“外观”可调整12–22号字，拖动立即预览、松开自动保存，恢复标准为14号。设置保存在当前安装的数据目录，重开程序仍保留；不会改变发送消息的字体格式。

“插件与聊天”按类别分组，每个插件可直接选择分类；能力目录可按相同分类筛选。点击“管理分类”可新建或改名，分类名最多24字；默认分类可改名，删除自建分类只把其中插件移入其他插件，不卸载插件、不更改权限。分类与字号都不会改变聊天授权。

语音音色页按日常语音、音色库、合成引擎、环境检查整理。日常语音设置回复概率和默认音色；音色库负责参考录音、自定义及随机音色；合成引擎负责本机模型和外接API；运行组件导入在环境检查中。翻唱清晰度、伴奏音量和人声素材导入在音乐页。

## 音乐制作状态与失败处理

分离和换声阶段会显示当前段/总段数。整曲换声按短片段上传，适配本机服务16MB单次限制；分离也使用短片段并合回原时间轴，减少内存占用。歌曲最后才按一分钟片段或完整模式编码发送。看到“内存不足”时应关闭暂不用的模型或程序后重新点歌；看到送达不明不要反复重发。旧失败任务不会因更新而自动重新投递。
