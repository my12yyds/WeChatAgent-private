# 群聊定向回复与 @

明确回复某位当前发言者时，可用 `RESPOND:` 后的 `[REPLY_TO:成员ID]` 指定目标。候选仅来自当前群本轮真实发言，按稳定 ID 核对；不从转发记录或同名推断身份。兼容正文开头唯一名字，同名必须明确 ID。

同轮仅第一条文字携带 @，后续分段和表情不重复。同一成员近期已被提醒时抑制重复提醒；当前窗口为 10 分钟，并读取已确认/未确认的发送记录，重启不重置。面向全群、私聊或仅提及第三人不添加提醒，不支持 @ 全体。

Hook 发送前重新核对成员与账号，读取本次原生组件能力快照并生成 at_user_list。前台模式改为普通文字称呼。当前主适配目标为微信 4.1.10.27，其他版本的历史接口不作为已支持依据。

若私聊正常、群回复已生成却没发出，检查 `NATIVE_MENTION_UNAVAILABLE`。适配器已修复 nativeMentionSend 健康标记映射，并使用本次核验快照避免后台轮询误覆盖。组件确实不支持时仍在提交前拒绝，不伪报 @ 成功。

同一发送编号绑定原成员；已提交但回执未知不盲目重发。回归：`node --test scripts/test-group-mentions.mjs`。隔离测试使用模拟群和回执，不等同真实客户端通知验收。
