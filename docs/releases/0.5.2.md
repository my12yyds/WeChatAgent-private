# WeChatGirl 0.5.2

本次更新将 Windows 安装、启动与卸载改为图形界面，并补齐语音识别插件的宿主链路。适用 Windows 10/11 x64，主适配微信 4.1.10.27；DSH 独立安装。

## 安装与启动

- 安装版使用 Electron Builder + NSIS 中文向导，支持选择安装根目录、系统应用列表和快捷方式；完成后可以启动程序。
- 便携版完整解压后双击根目录的 WeChatGirl.exe，无须打开 CMD。启动器清理会让 Electron 误进命令行模式的环境变量，缺失文件时用图形提示说明。
- 安装与卸载遇到程序占用时提示保存设置并完整退出，不强制结束进程。卸载保留 data、storage.ini 和用户额外添加的文件，仅删除安装清单中的程序文件。
- 修复干净安装缺少 htmlparser2 等运行依赖而启动失败的问题；按锁文件准备必需依赖，并在打包前使用内置 Node 实际导入 SDK 和控制台。
- 安装协议正确显示中文，卸载页说明用户数据保留范围，删除不可用的所有用户安装选项。

## 微信语音识别

- 随附 speech-recognition 1.3.0，参考上游固定提交并保留来源和许可。
- 补齐语音消息接收、受控音频读取、DSH 转写动作及聊天回复链路，增加完整能力标记，防止旧宿主错误启用新版插件。
- 配置页可选择协议、读取模型列表、检查转换组件、测试合成短句和查看最近识别状态。高级参数折叠；不会自动上传聊天语音或扩大聊天权限。
- 插件包升级不替代宿主升级。使用前配置自己的识别服务和模型，并为所需聊天显式授权。

## 更新与升级

仓库规范地址为 [my12yyds/WeChatGirl](https://github.com/my12yyds/WeChatGirl)。修复更名后下载地址与更新检测不一致的问题；旧版如无法检测更新，请直接下载安装包。

升级前保存草稿并从托盘完整退出旧程序，选择已有根目录，保留同级 data。安装后按配置向导检查连接。语音插件接口更新需要从 DSH 托盘完整退出再重新打开；仅关闭窗口可能仍驻留后台。

音乐、声音工作室、人物记忆、发送模式和其他已有插件继续保留。语音运行组件仍是可选附件，不等于完整模型；外接语音 API 和网易云音源权限需自行配置。

## 验证与附件

本次在 Windows x64 使用隔离目录与虚构数据验证：中文路径新装、同目录升级、自定义数据位置、运行时拒绝安装/卸载、卸载保留用户及非程序文件、GUI EXE 与启动环境。完整便携版在全新数据目录成功打开配置向导；检查图形安装协议、目录步骤和卸载说明。

215 项 Node 隔离回归通过。发布前另核对插件宿主与随附插件包、归档全条目 CRC、部署清单和 SHA-256。具体结果见附件 VALIDATION.json；每个安装包与对应源码使用同一版本。

提供安装器、便携 ZIP、可选语音组件、SHA256SUMS.txt、VERIFICATION.json 和 VALIDATION.json。未自动向真实微信聊天发送消息，未在第二台物理设备完整验收，未验证所有外接服务或真实收件端播放。安装器未做商业代码签名。保留 0.5.1 的提交、标签和 Release 供回退。
