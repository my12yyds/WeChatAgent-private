# WeChatGirl 0.5.6

## 下载哪个包

普通用户下载 **Windows 安装版**即可开始配置。便携版是另一种启动方式，两者任选其一。

## DSH 修复补丁

已安装 0.5.6 的用户可下载 [DSH 修复补丁](https://github.com/my12yyds/WeChatGirl/releases/download/v0.5.6/WeChatGirl-0.5.6-DSH-hotfix.zip)，按 [安装步骤](0.5.6-dsh-hotfix.md) 覆盖四个程序文件。首次安装请先装主包并启动一次，再应用补丁。

补丁修复新版 DSH 在调用模型前筛选工具清单时报错的问题，并让已授权管理员用 `/dsh 任务` 在聊天中单独交办任务。

## 本版更新

- 内置音色的本机试听直接调用合成引擎，避免等待唱歌共用的换声队列。自定义音色可以继续使用额外换声。
- 语音设置先选本地模型或外接 API。API 音色 ID 支持清单选择，音乐和语音制作进度各有常驻区域。
- 鲸鱼娘前台可恢复最小化的微信，等待搜索结果后核对目标，并点击微信发送按钮。发送失败保留具体原因。
- 修复旧桥接进程号被系统复用后阻止重启、SQLite 警告阻止一键打开 DSH，以及档案检索小数参数阻止保存。
- 降低整曲人声分离的内存占用，备用 CosyVoice 模型首次使用时加载。
- 音乐完整音源继续由网易云提供，QQ 音乐与酷狗提供官方入口。

Windows 10/11 x64。完整收发适配微信 4.1.10.27 x64，DSH 需单独安装。升级前请从托盘退出程序，保留原 data 目录。
