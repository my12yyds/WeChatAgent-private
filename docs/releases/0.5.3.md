# WeChatGirl 0.5.3

本版增加微信版本检测和内置匹配版入口，改进 DSH 模型限流错误提示。适用 Windows 10/11 x64，完整收发使用内置微信 4.1.10.27 x64，DSH 独立安装。

## 微信版本与内置匹配版

- 配置向导“连接微信”和连接设置增加版本检测卡，区分当前选择、内置匹配版、常见安装位置及正在运行的微信。
- 校验 EXE 与核心 Weixin.dll 的版本、x64 架构、腾讯数字签名，以及对应发送组件的版本和哈希。文件不完整或不匹配时禁止启动。
- 点击“使用并打开内置匹配版”，通过正常配置保存和启动流程使用随包准备的 4.1.10.27，无须另找旧版安装包或手填工具版本。
- 切换前提示处理未保存草稿和正在使用其他客户端的助手服务；其他微信运行时不强制关闭，也不替换系统微信。进程冲突检查移至组件写入之前。
- 未验证的新版仅显示检测和兼容性提示，不套用旧版发送组件。检测到新版不代表已经适配其完整收发。

## DSH 模型诊断

识别被包装在 turn_error 中的上游 429/42908 限流，提示稍后重试或选择其他可用提供方；保留会话接收与防重复边界，不自动重放已接收请求、不自动换模型，也不展示上游原始响应。

此改动不能解除供应方限流；DSH 插件连接正常也不等于上游模型当时可用。

## 升级

先保存设置并从托盘完整退出旧程序，再安装到原根目录，保留同级 data。完整重开 WeChatGirl 后，新入口显示在配置向导和连接设置中。内置微信首次使用仍需自行登录并验证账号；系统微信与内置客户端的登录状态不自动复制。

沿用 0.5.2 的 NSIS 中文图形安装/卸载、原生 EXE 启动、音乐、声音工作室、人物记忆和语音识别功能。配置、人格、插件和状态继续保留，旧 Releases 与标签保留供回退。

## 验证与附件

223 项 Node 隔离回归通过，覆盖检测授权、缓存、版本/签名/核心不匹配、模型限流和防重复边界。本机只读检测确认内置 4.1.10.27 校验通过，系统 4.1.15.56 显示为未验证完整收发；深色与 520 像素窄窗口无横向溢出。

发布前另核对同版本隔离安装、升级、卸载保留、运行时拒绝修改、完整程序启动、插件宿主、归档 CRC、部署清单、源码与 SHA-256。结果见附件 VALIDATION.json。

提供安装器、便携 ZIP、可选语音组件、SHA256SUMS.txt、VERIFICATION.json 和 VALIDATION.json。未自动向真实聊天发送消息，未在第二台物理设备完整验收，未完成最新版微信的完整收发适配；安装器未做商业代码签名。语音组件不包含全部模型或外接服务授权。
