# WeChatGirl 0.5.4

本版修复干净安装缺少读取组件，并为 API v2 插件设置加入 Windows 当前用户加密。适用 Windows 10/11 x64，匹配微信 4.1.10.27，DSH 独立安装。

## 安装包完整性

- 修复 0.5.3 未包含 wx_key.dll，导致新电脑“一键连接并验证”出现 READER_KEY_COMPONENT_MISSING 的问题。
- 从已登记的旧发行组件显式复制该文件，核对 SHA-256、x64 DLL 格式及所需导出；不从未知网站临时下载。
- 核对组件进入模板及部署清单，首次启动复制到实际 workspace。缺件、误换或只在模板中存在却未部署的载荷直接停止构建。
- 保留标准 NSIS 图形安装、升级与卸载；账号配置、人格、插件及状态不随公开安装包分发。

## 插件设置加密

API v2 插件的整份设置使用 Windows 当前用户 DPAPI 加密后保存，覆盖 API Key、自定义请求头及其他参数。界面仍按 secret 声明隐藏秘密字段；获准运行的插件在内存中按正常方式读取自身设置。

旧版本的活动插件配置在读取时原位迁移到加密格式，保留启用状态、授权、聊天范围及 generation，不额外生成明文备份。加密或解密失败时保留原文件并停止使用，不回退到明文；并发修订不会被静默覆盖。

加密保护不等于阻止所有外传：同一 Windows 账号下的恶意程序仍可能访问运行中的数据；外部模型和语音服务仍会接收对应功能所需的聊天或音频；旧备份中的历史明文不会自动删除。原 wx_key.dll 保持原样且未签名，本次完整性核验不能作为它的完整安全认证。

## 升级与替换

先保存设置并从托盘完整退出 WeChatGirl 和 DSH，再安装到原根目录，保留 data。安装后重新打开两者并检查连接；新版 DSH 插件宿主契约为 wechatagent-plugin-v2.5。

加密配置格式为 version 2，0.5.3 及更早宿主不能直接读取，需要一起升级。回退时需在旧版本重新配置插件，不提供自动写回明文的降级。换 Windows 用户或电脑后，可能需要重新填写插件凭据。

0.5.4 将作为最新版，替换 0.5.3 的正常下载入口。新附件全部核对通过后撤下 0.5.3 的缺件安装器与便携包，保留历史提交、标签和 Release 记录。

## 验证

230 项 Node 隔离回归通过，包含真实 Windows DPAPI 的合成凭据往返、独立 Node 进程解密、迁移保留权限、并发修订、密文损坏与失败不回退。另验证读取组件的缺失/误换拒绝、导出检查、首次实际部署及缺件恢复。

发布前还需完成新版本隔离安装/升级/卸载、内置 Python 只读依赖检查、完整程序启动、插件宿主、归档 CRC、源码及部署哈希、远端附件 SHA-256。具体结果以 VALIDATION.json 为准。

提供安装器、便携 ZIP、可选语音组件和校验/验证文件。未向真实聊天发测试消息，未采集用户真实数据库密钥，未验证第二台物理设备。安装器未做商业代码签名。
