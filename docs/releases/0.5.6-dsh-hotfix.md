# WeChatGirl 0.5.6 DSH 修复补丁

适用于已经启动过至少一次的 Windows 安装版或便携版 0.5.6。补丁修复新版 DSH 在调用模型前筛选工具清单时报错的问题。管理员可用 `/dsh 任务` 在已授权的聊天交办任务，仍按聊天配置授权并遵守 DSH 审批。

1. 从系统托盘完整退出 WeChatGirl 和 DeepSeek Harness。
2. 找到包含 `app` 和 `data` 两个文件夹的 WeChatGirl 根目录。确认其中存在 `data/workspace` 与 `app/resources/project`，并将补丁 ZIP 解压到临时目录。
3. 把补丁内的 `app` 和 `data` 文件夹复制到 WeChatGirl 根目录，选择合并文件夹并替换同名文件。补丁中的两个目录各包含相同的四个程序文件。复制时保留根目录现有的所有文件夹和文件。
4. 打开 WeChatGirl，再打开 DSH，并检查工作台连接状态。如果此前已添加 WeChatGirl 插件，直接重新打开 DSH 即可。
5. 用管理员账号在已授权的聊天发送 `/dsh 查看当前工作区有哪些项目`。需要审批时在 DSH 界面确认。

初次安装请先安装 0.5.6 并启动一次，再按上述步骤应用补丁。
