# WeChatGirl 0.5.1

本版已完成下列构建与隔离检查。下载请前往对应 Release；仓库及附件公开可访问，程序可查询公开发行记录。

## 配置与界面

- 首次打开进入配置向导，基础检查覆盖微信、DSH、模型、发送模式、服务与聊天；可选功能按插件声明发现并提供配置入口。
- 插件与聊天页同页选择群聊/好友并分配插件，保留能力页的参数、权限和范围管理。
- 页面返回、向导滚动保持、视图过渡、音乐折叠配置，以及托盘/更多菜单的服务操作。
- 重写项目首页、维护指南和主要专题，新增文档索引与发送模式对照，清理旧导航、旧路径与不准确的依赖描述。

## 模型、音乐与声音

- DSH 模型目录保留能力元数据；主模型能看图时直识，否则可分流到备用模型，提供内置/上传图片测试。
- 音乐页提供网易云登录、站内搜歌、音源权限检查、歌曲气泡列表和已制作成品复用。
- 声音设置包括自定义与随机音色、部分句子随机改发语音、发送节奏、清晰人声与伴奏音量。
- 默认调用本地部署；用户可选兼容语音 API。参考录音留在本机，外接模式会向服务发送待合成文字。

## 发送与插件修复

- 前台与 Hook 整套发送能力隔离，前台不回退 Hook；语音、文件和指定表情等限制在独立页面说明。
- 修复群回复原生 @ 能力映射及并发状态误覆盖；同轮仅第一条文字提醒，保留近期重复提醒抑制。
- 表情页新增离线启动/诊断，批量导入中断保留成功项；相同 GIF 不同投递严格关联回执。
- 第一方可导入插件、人物事实召回和群友互动记忆继续使用独立权限与数据边界，随附包不代表自动启用。

## 升级注意

保存草稿后退出旧程序，同目录升级保留用户数据。DSH 插件接口变化需要从托盘完整退出再打开。当前主适配微信为 4.1.10.27 x64；DSH 单独安装。语音运行组件不等于完整模型，自定义说话参考不会自动替换歌唱模型。网易云账号仍受平台音源权限限制。

## 验证状态

本次在 Windows x64 执行：

- 162 项 Node 隔离回归通过，插件宿主与九个可导入包检查通过。
- 主要说明的本地链接检查通过，源码差异空白检查通过。
- 安装器数据段检查、隔离初装和同目录覆盖安装通过；未启动真实微信或助手服务。
- 桌面部署初始化通过，默认聊天允许列表为空；重复部署保留配置、插件权限、人格、用户插件和状态五类虚构测试数据。
- 便携包与可选语音 ZIP 全条目 CRC、路径与隐私排除检查通过，发行附件 SHA-256 核对通过。语音环境自带 certifi 公共 CA 证书不是用户私钥。
- 修正旧二进制基线的客户端版本不匹配，重新核对 4.1.10.27 EXE、核心 DLL、Hook 目标与 SHA-256；不复制客户端根目录的本机令牌。

本机产物为安装器、便携 ZIP、可选语音组件、SHA256SUMS.txt 与 VERIFICATION.json。便携包约 596 MiB，比原 0.4.4 产物约缩小 17.6%；精确大小和哈希以最终附件为准。

未自动向真实聊天发送消息；未在第二台物理设备完整验收，未验证所有外接 API，也未执行真实账号的扫码、唱歌与收件端播放回归。卸载数据边界保留源码检查，未在本次运行卸载程序。安装器未做商业代码签名。本版源码、日志和附件按同一版本发布。按维护者要求，仓库仅保留 0.5.1 的源码快照与发行附件。
