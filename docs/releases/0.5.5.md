# WeChatGirl 0.5.5

本版在0.5.4基础上整合当前工作区功能，升级保留本机配置、插件、人格与数据，不发布个人账号和聊天资料。

## 音乐与语音

- 整首翻唱按歌曲合并显示，详情使用独立顶层浮层，不被下方卡片遮挡。支持单首、多选、筛选后全选删除；正在制作或投递的歌曲受保护。
- 可配置生成成品保留数量，默认不限制，超限清理最旧且未在使用的成品；完整多段按一首，导入人声不自动清理。
- 缺少本地语音运行组件时，音乐页置顶显示导入入口；环境、模型和微信发送能力分别检查，不把导入环境等同于全部模型已齐。
- 一分钟模式先裁取最多60秒再处理，发送一条语音；整曲模式当前支持10分钟以内，转换后拆成每段最长55秒。保存默认方式，点歌时可临时指定。
- 修复整曲上传超过16MB和分离内存不足，增加分段进度、换声缓存和回执控制；语音音色与音乐分开管理，本地模型、外接API与CosyVoice3可选。

## 聊天、记忆与界面

- 人物记忆工作台、持久档案混合检索、事件约定、虚构长对话评测和自然群聊节奏可分别控制。
- 图片分流、表情来源、发送方式和按聊天分配插件保留现有功能与权限。
- 12–22号字、可自建插件分类、语音音色四区与折叠高级设置；修复DSH重复启动后临时认证Cookie累积问题。

## 插件分发

主包只随附人物记忆、人格工作室，首次准备代码但默认关闭；其他13个插件按需下载。每个插件提供独立ZIP和详细说明，另有15个插件总包，可在能力目录一键下载并导入。总包跳过已有插件，不覆盖自定义代码或自动授权。完整索引见[插件目录](../plugins/README.md)。

## 升级与验证边界

升级前从托盘完整退出WeChatGirl和DSH，保留原data。模型和本地运行环境不进入插件ZIP，语音组件作为独立附件提供。当前微信适配目标仍为4.1.10.27 x64，不宣称任意微信版本兼容。安装包不包含你的私有登录、聊天、人设或本机模型权重。

隔离测试、打包清单、校验和及实际安装验证随发行产物记录；未自动向真实微信发送测试消息。
