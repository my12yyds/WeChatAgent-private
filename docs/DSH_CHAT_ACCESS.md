# 按聊天分配模型与 DSH 能力

DSH 管理模型提供方、技能和第三方 DSH 插件；WeChatGirl 管理微信允许范围、人格、聊天模式及每个聊天的能力分配。安装技能或插件不等于对微信群开放。

## 配置入口

1. 在“聊天”加入允许的好友或群聊并保存。
2. 选中目标，打开“设置此聊天”，配置人格、模型、模式与回复方式。
3. 在“能力与权限”选择任务预设及所需技能、工具，保存当前聊天。
4. DSH 新增工具后刷新清单；插件代码更新时可能需从托盘完整重开 DSH。

单聊保存不覆盖其他页面草稿。聊天模式与助手模式保留各自上下文；模型目录来自 DSH，目录可见不证明真实账号额度或调用成功。群聊可独立继承默认、自然参与或唤醒后回复。自然参与可能调用模型后选择沉默，仍有消耗。

## 身份与权限

DSH 执行需要真实管理员身份、本聊天授权以及原生权限。助手群允许普通成员社交聊天，但不把管理员工具、文件和任务控制交给普通成员；私聊助手仅供指定管理员。管理员 DSH 插件可在聊天模式申请任务，仍走相同身份和授权边界。

技能是操作说明，工具才执行动作。逐项授权时，只提供该聊天已选能力；明确选择“使用 DSH 可用能力”时按所选预设的实际目录处理，不能把普通勾选插件误当作授权全部工具。调用仍经过 DSH 的权限与审批，这不是操作系统沙箱。

微信原生发送、主动聊天与上下文维护由宿主管理。WeChatGirl ZIP 插件另有参数、权限和聊天范围，详见[插件目录](PLUGIN_CATALOG.md)。

## 离线、撤权与账号切换

未加载的既有工具保留授权展示，可取消，不因目录暂缺丢失设置。来源未知的工具明确列出，不按名字猜来源。切换账号不会继承上一账号群权限。

撤权阻止后续未提交动作；已发生的外部动作不保证回滚。DSH 重启中断的任务不自动重跑，先核对实际结果再重新交办。连接失败检查[DSH 接入](EXTERNAL_DSH.md)，任务说明见[远程助手](ASSISTANT_REMOTE.md)。
