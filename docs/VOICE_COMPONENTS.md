# 语音组件下载与导入

发行包将较大的本地语音环境单独放在 `WeChatGirl-voice-components.zip`。主程序仍包含网页播放、音频处理和微信语音编码相关实现；这个附件不包含所有合成模型和服务。

## 在程序内导入

1. 更新并完整重开 WeChatGirl，进入左侧“音乐”。
2. 找到“语音组件管理”，查看 Python 环境、WSL 镜像和本地模型文件状态。
3. 点击“下载语音组件包”，从指定的项目发行附件下载 ZIP。当前登记附件来自 v0.5.4，适配后续导入界面；请使用页面入口，不要重新压缩后再导入。
4. 点击“选择 ZIP 并导入”，在本机文件窗口选择下载的组件包。无需手动解压，也不用选择安装目录。
5. 程序核对文件大小、SHA-256 和归档目录，显示校验字节数、解压文件数及安装阶段。导入期间等待完成后再退出、升级或重启程序。
6. 完成后点击“重新检查”。组件放在**当前实际数据目录**的 `voice-python`、`voice-wsl`，与 `workspace` 同级；数据目录迁移过时，也使用当前目录。

已有环境目录保留，不合并覆盖。显示“目录存在但不完整”时，本功能不会删除或修复该目录，应先备份并由维护者核对。完整环境不需要重复导入。

## 导入后还需要什么

附件包含补充 Python 环境和 WSL 根文件系统镜像。导入只复制文件，不执行包内程序，不注册 WSL，不启用插件、不扩大聊天授权，也不自动发送语音。

本地说话还需要说话引擎、模型与服务配置；唱歌还需要对应模型、音源和服务。组件管理区报告文件是否存在，实际运行状态由声音工具的检查结果确认。参考录音、API 凭据和已生成歌曲不随公开组件包分发。

使用外接语音 API 时，在音乐页“语音合成来源”配置服务即可，无需导入这个本地环境包；外接服务会收到待合成文本。微信原生语音仍需 Hook 模式及相应组件就绪，详见[声音工作室](VOICE_STUDIO.md)。

## 导入失败时

- 校验不一致：使用页面入口重新下载，不导入任意 ZIP。
- 空间不足：在实际数据磁盘预留至少 600 MB 空间。
- 目录存在或不完整：原目录保留，不要为了重试删除整份 data。
- 另一个实例正在导入：等待完成。异常断电后持续提示时，先退出所有 WeChatGirl，备份后由维护者核对 `.voice-components-import.lock` 和暂存目录，确认没有导入进程再恢复；不自动清理来历不明的数据。
- 接口不可用：保存设置并完整重开更新后的 WeChatGirl。

失败前已安装的新目录可能保留，重新检查可看到实际结果。原账号配置、模型、音色和歌曲不会被覆盖。

## 维护组件版本

`packaging/windows/voice-components.json` 登记附件版本、链接、字节数、SHA-256、目录和必要文件。新包需先审核来源、许可、内容与隐私边界，再更新登记并完成隔离测试。不能只改链接或接受用户提供的任意摘要。

构建用 `-VoiceComponentsZip <已登记ZIP路径>` 复用附件。同步脚本会在开发机的 `release/artifacts-<登记版本>/` 查找；未提供时可只发布主程序，音乐页仍可下载登记附件。不要从活动数据目录重新压缩环境。

使用 `node scripts/verify-voice-components.mjs <ZIP路径>` 校验附件。测试通过 `WECHATAGENT_TEST_PYTHON` 指定已安装 Python；设置 `WECHATGIRL_TEST_VOICE_ZIP` 后会额外导入真实附件到一次性目录，核对重复导入保留原文件，不执行包内二进制。
