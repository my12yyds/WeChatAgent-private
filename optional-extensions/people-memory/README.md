# 人物记忆 1.1.0

本机按真实微信发送者ID区分人物，同名不合并。已授权聊天中，本人直接陈述的简单昵称和偏好自动保存，回复前按本人的当前发言检索并注入相关记忆，不依赖模型每次主动调用。工具仍支持其他明确记忆与忘记请求，但text必须为本人发言中的连续原句片段。假设、转述、引用、否定记忆、敏感凭据或系统权限指令不自动保存。

默认只在原聊天使用，跨聊天使用需本人明确说“跨聊天记住…”等允许，询问或否定共享不算同意。源聊天撤销授权后，来自该聊天的共享记忆不再召回。简单昵称更新、相同偏好正负变化会保留旧条目的软删除记录；忘记后重放同一条旧消息不会复活记忆。记录180天后过期，账号之间隔离。

记忆页面“查看人物记忆”可看人数/条数、已授权聊天数、自动保存/召回状态、最近向模型提供的记忆数，支持搜索及确认忘记。已有记录格式保留，不扫描或回填全部聊天历史。

原项目的群友记忆继续使用单独的群内记录：稳定ID、历史昵称、互动标签。群友记忆开启时，对简短表达/提问只累计直接可见的独立消息证据，至少三条才作为稳定的表达参考；不重复累计同一消息，不推断敏感属性。已确认的标签自动提供给本轮在场成员的回复上下文，不带入其他群。原有标签和本人明确事实彼此补充，不把群内观察变成跨群人物事实。
