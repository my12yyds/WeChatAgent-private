# AI 人格工作室 · 1.1.0

1.1.0 新增本机 `preview` 动作：校验编辑后的草稿并返回 Markdown，不调用模型、不保存或启用人格。当前 WeChatGirl 控制台在“人格”页提供工作室入口，支持灵感提示、连续修改、手动编辑、撤销、Markdown 下载和确认导入。生成动作使用 45 秒页面等待预算，避免原来 20 秒提前中断。新版界面需要配套更新控制台文件；ZIP 自身仍不注入前端代码。

这是 **WeChatGirl 插件 API v2 ZIP 插件**，用于新版“能力 → 能力目录”，不是 DSH/npm 插件，也不是旧版 Python 扩展。无需安装依赖。不会改变当前项目的默认启动方式。

## 安装与使用

1. 在新版能力目录安装 `persona-studio-1.0.0.zip`，核对权限并确认。
2. 在插件配置中授权 `storage`、`model_generate`，选择允许使用的聊天，再开启“允许此插件运行”。建议先仅分配给自己的私聊；群聊里获宿主授权的工具使用者也可以设计各自人格。
3. 如果提示“等待新版宿主”，准备配置、完整退出并重开 DSH，再重启新版后台。宿主必须支持 `actions-v1` 和 `model-utility-v1`，不能只凭 API 版本号判断。
4. 在授权聊天中说：“帮我设计一个温柔、简短回答、喜欢音乐的人格，先给我看草稿。”模型会先读取版本，再把设计稿交给 `persona-studio__draft` 保存。
5. 继续说：“保留其他设定，把语气改得活泼一点。”也可以说“预览我的人格草稿”“导出我的人格 Markdown”。
6. 把导出内容保存为 UTF-8 `.md`，在新版人格页面选择导入、预览并确认使用。**插件不会自动导入、覆盖或启用人格**：API v2 尚无人格写入接口，也不提供文件附件发送接口。聊天返回的是文件名和文本，不是已经保存到磁盘的附件。

普通聊天不应触发人格修改。模型根据描述决定是否调用工具，安装成功不保证每条消息都调用。宿主的管理员限制和聊天授权仍然生效。工具错误、停用不应阻塞普通回复。

## 功能和数据

- 多轮设计依赖当前草稿；每次保存完整设定，保留最近三版用于后续扩展。预览返回当前版本，不回传整个设计历史。
- 草稿使用宿主 `actorStorage`，按账号、插件、聊天和真实发送者隔离；识别不到发送者时拒绝读写，不退回共享存储。工具无跨账号、跨聊天、跨成员参数。
- `save` 和 `reset` 需要先 `view` 获取 `expectedRevision`，避免顺序调用时用旧预览覆盖新内容。宿主没有原子比较写入 API，不应从多个会话同时编辑同一个人的同一草稿。
- 清空需要明确确认，`reset` 的 `confirm` 必须为 true。更新、停用、卸载遵守宿主数据保留规则。
- `storage` 用于草稿和最近三版；不读聊天历史、不读取账号密钥，不直接访问本机文件，不联网、不启动定时器、不自行发送微信消息。
- `model_generate` 仅用于下面的本机生成动作，复用宿主当前配置模型。对话设计使用主对话模型，不额外嵌套调用模型。**两种方式均使用各自模型额度**。
- 人格长度限制为正文 2200 字、示例最多 4 条，每条 180 字，确保工具回复和模型动作结果有界；不迁移旧版的 temperature/max_tokens，它们是模型设置而不是新版 Markdown 人格字段。

## 本机页面接入（可选，不附带前端注入）

动作 `generate` 专供新版已认证页面接入，最长 35 秒外层预算，内部模型请求最多 25 秒。不是 8 秒模型工具，不会因生成较慢占住普通工具预算。只生成预览，不保存、不启用；多轮修改时把上一轮返回的 `draft` 原样带回。宿主没有通用自定义动作页面，本 ZIP 不会凭空增加页面按钮。

请求：`POST /api/plugins/persona-studio/actions/generate`，使用宿主控制台的 `X-Console-Token`，并满足 Host/Origin 检查。仅从可信本机管理页面调用，不把控制台令牌发给微信用户。

```json
{"key":"wechat:private:已授权聊天ID","args":{"message":"设计一个温柔、简短回答的人格"}}
```

修改：`args` 中加入上一轮 `draft`。返回含 `draft`、`preview`、`filename`、`saved:false`、`applied:false`。页面可让用户复制或下载 `preview`，通过新版原有人格导入流程确认。非法、截断或不完整模型输出会失败，不保存半成品，不自动重试计费请求。

## 开发验证和打包

在新版项目目录运行：

```powershell
node --test scripts/test-persona-studio-plugin.mjs
node scripts/pack-plugin.mjs optional-extensions/persona-studio release/plugins/persona-studio-1.0.0.zip
```

ZIP 仅含清单、入口、相对路径模块及本说明，无账号、密钥、模型固定值、安装脚本或 node_modules。安装和升级需用户确认；包不会默认启用，不会自动授权聊天。
