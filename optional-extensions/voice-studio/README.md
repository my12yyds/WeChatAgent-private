# 肥鱼声音工作室 1.3.0

在 WeChatGirl“能力 → 能力目录”导入，配置 storage / voice 权限，选择聊天并启用。“插件与聊天”可直接调整聊天范围；音乐页提供声音参数、音色和任务面板。随附 ZIP 不会自动安装模型或授予权限。

## 说话与音色

可说“用语音说晚安”“改成温柔音色”“查一下语音进度”“停止唱歌”。支持 B 明亮可爱、A 自然可爱、温柔音色，以及音乐页管理的自定义默认音色和随机候选。自定义参考用于说话，不自动训练歌唱模型。

当前插件默认随机语音替换开启，概率 25%、同聊天冷却 90 秒；用户可修改或关闭，旧设置沿用保存值。单轮最多替换一句 6–90 字普通句子，代码和链接不转换；制作失败在权限仍有效且未提交微信时补发原句文字，已提交但回执未知不重复补发。全部短回复附带语音在随机替换关闭时使用。

默认本机 Breeze 合成与可选肥鱼换声。需先准备对应运行环境和模型；也可在音乐页主动配置兼容 /audio/speech 且返回 WAV 的外接 API。外接会发送待合成文字并可能计费，不上传本地参考录音。密钥在当前 Windows 账户加密保存。

## 唱歌与成品缓存

支持准确歌曲搜索、网易云歌曲链接、本机曲库和 ABC 曲谱配对齐歌词。在线点歌按账号真实权限获取音源，分离人声/伴奏、肥鱼换声并混音，默认约 55 秒片段，不任意替换歌曲版本或绕过会员限制。

成品保存本机 WAV 与 SILK；歌曲来源、账号、音色、模型和混音参数匹配且文件有效时直接复用。cachedOnly 只查本机，缺失时不联网。清晰人声与伴奏音量进入制作指纹，修改后制作新版本，保留旧成品。

## 排队、发送与限制

制作和发送分开排队，已完成音频不等待长曲制作。默认发送间隔 2 秒、每聊天每分钟 6 条、十分钟 30 条，设置可调整；不把文字和表情计入语音额度。实际阶段和等待原因可在音乐页查看，不用虚构百分比掩盖耗时。

原生语音最长 60 秒，必须 Hook 发送能力就绪；前台模式禁用语音气泡和歌曲投递。“生成完成”“接口接受”“服务器回执确认”分别记录，回执不足不声称送达，响应丢失先核验而不重发。账号切换、撤权或取消阻止尚未提交任务，已提交不承诺撤回。

所有模型、参考录音、账号音色、歌曲和任务数据位于运行工作区 state/voice，不进入源码或插件 ZIP。本机试听不发微信；明确点击测试发送会使用选定的已授权聊天。完整配置、依赖、数据与声库许可见[声音工作室说明](../../docs/VOICE_STUDIO.md)。
