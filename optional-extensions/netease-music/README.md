# 网易云音乐 1.1.0

控制台左侧「音乐」是独立工作台：网易云站内搜索、手机扫码登录、退出登录和本机曲库。声音工作室和网易云插件配置都有入口。后台唱歌和聊天搜歌使用同一套站内搜索；无需把登录凭据发给模型。

扫码请使用网易云手机应用，并由用户本人确认。登录凭据通过Windows当前用户DPAPI加密，存放state/netease/session.json；仅向固定网易云接口发送，不写入日志或模型上下文。退出登录清除本机凭据，不登出其他设备。网络暂时失败保留本机凭据，账号失效可重新扫码。

登录不保证每首歌曲都可提取，以网易云返回的播放链接与实际权限为准；不处理付费解锁、挑战验证或受限试听片段。已完成歌曲仍按原微信账号与音色保存、校验、复用，聊天授权范围不变。曲库自动刷新；聊天通过声音插件唱歌，独立页面搜索本身不向微信发送消息。
