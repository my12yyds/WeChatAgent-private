# 管理员 DSH 助手 1.1.0

支持聊天模式和助手模式。需要 WeChatGirl 的 admin-dsh-v1、chat-dsh-access-v1 宿主能力；旧版本宿主需要一起更新。

在“聊天 → 设置此聊天 → 能力与权限”中打开“聊天模式调用 DSH（仅管理员）”，再勾选工具与技能，并设置每轮调用次数（10–100 次）。聊天模式默认关闭，开关关闭时勾选内容保留但不执行；不同聊天分别授权，普通群友和身份不明的发送者不能使用这些能力。管理员名单在“设置 → 助手设置”中管理，使用真实微信 ID。

例如：勾选 read、glob、grep 可查看和检索文件；勾选 write、edit 可修改文件；勾选 pwsh 可执行命令。命令工具可组合多步操作，授权时应按实际需要勾选。DSH 自身工作区及审批继续生效，默认在 DSH 本机确认，本插件不会自动批准或扩大权限。聊天模式保留当前人格、原历史，在当前轮按需调用，不创建助手持久任务队列。没有对应授权时应说明缺少能力，不宣称完成。

普通闲聊直接回答；管理员明确说“帮我检查这个项目的报错”时，可使用本聊天勾选的工具。群聊多人混合消息批次不能继承其中管理员身份。每次调用重新读取本机配置；撤销工具、关闭开关或移除管理员后后续调用立即失效。工具列表只来自真实 DSH 清单，勾选工具名才授予该工具；技能说明本身不授予执行权限。

助手模式继续提供持久任务队列、进度、结果和取消，支持“助手能力”“任务列表”“任务状态”“取消任务”等微信命令。聊天模式里的本插件工具可以查询已有助手任务和能力；当前轮执行的普通工具没有独立任务编号。长任务建议切换助手模式。

插件停用只移除其辅助任务工具与上下文说明。要关闭聊天模式中的 DSH 执行，请关闭本聊天的“聊天模式调用 DSH”开关；助手模式的原生能力是独立配置。停用或撤权不会回滚已经完成的文件修改，也不会强制停止已经提交到 DSH 的后台进程。
